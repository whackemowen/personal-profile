# personal site

minimal terminal-style personal profile built with Next.js + Tailwind.

## stack

- **Next.js** (App Router)
- **Tailwind CSS**
- **Geist Mono** font

## dev

```bash
npm run dev
```

open [http://localhost:3000](http://localhost:3000)

## structure

```
app/
  layout.tsx   # root layout, font, metadata
  page.tsx     # main page — edit content here
  globals.css  # base styles
```

## deploy

push to GitHub, connect to [Vercel](https://vercel.com) — done.
